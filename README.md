## แนวคิดการออกแบบ
-ใช้ Three.js ในการสร้างฉากจำลองธรรมชาติแบบ 3 มิติ โดยไม่พึ่งไลบรารีเสริมอื่น

-มุ่งเน้นให้ฉากมีความสมจริงและเคลื่อนไหวได้ เช่น พระอาทิตย์ตกและเมฆลอย

-ใช้รูปทรงเรขาคณิตพื้นฐาน (Sphere, Cylinder, Plane)สร้างวัตถุธรรมชาติ เช่น ต้นไม้ ทุ่งหญ้า และแม่น้ำ

-ใช้ GLTFLoader โหลดโมเดล 3D ภายนอก (ภูเขาและกระท่อม) เพื่อเพิ่มความสวยงาม

-มีการจัดองค์ประกอบให้สมดุลตามลำดับความลึก (ภูเขาอยู่หลัง, บ้านและแม่น้ำอยู่หน้า)

-เพิ่มแสงหลักจากพระอาทิตย์และแสงบรรยากาศ เพื่อให้เกิดเงาและบรรยากาศใกล้เคียงธรรมชาติ

-มีแอนิเมชันจำลองการเคลื่อนไหวของสิ่งแวดล้อม (พระอาทิตย์ตกช้า ๆ, เมฆลอยไปมา)

## องค์ประกอบหลักในฉากประกอบด้วย:

1.ท้องฟ้า (ใช้ Fog และสีฟ้าของฉาก)

2.พระอาทิตย์ (ทรงกลมมีแสงส่อง)

3.ภูเขา (โมเดล 3D ที่อยู่พื้นหลัง)

4.ทุ่งหญ้า (พื้นสีเขียวรับเงา)

5.แม่น้ำ (ระนาบโปร่งแสงสีน้ำเงิน)

6.กระท่อม (โมเดล 3D)

7.ต้นไม้ (Cylinder + Sphere จัดเรียงเป็นแถวอย่างเป็นระเบียบ)
